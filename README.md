# MANGYSTAU Travel — сайт үлгісі

## Құрылымы
- index.html — басты бет
- places.html — көрікті жерлер және санат бойынша сүзгі
- tours.html — турлар мен ұсыныстар
- contact.html — байланыс және өтінім формасы
- css/style.css — ортақ стильдер
- js/main.js — мобильді мәзір, сүзгі және өтінім әрекеті

## Іске қосу
`index.html` файлын браузерде ашыңыз. Интернет қосулы болса, сыртқы фотосуреттер мен Google Fonts жүктеледі.

## Маңызды
Бұл — дайын фронтенд демо. Бағалар, телефон және email — мысал ретінде көрсетілген, жарияламас бұрын нақты деректермен ауыстырыңыз. Өтінім WhatsApp хабарламасын дайындайды; автоматты брондау үшін backend/API және нақты WhatsApp нөмірі қажет. Фотосуреттер сыртқы Unsplash сілтемелерінен алынады.
